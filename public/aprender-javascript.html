Aprender JavaScript jogando: o jogo grátis em que você programa um robô

O HackBot é um jogo educativo em português no qual você aprende JavaScript escrevendo código de verdade. Nada de quiz chato: seu robô só obedece ao que você programar. Se o código estiver certo, ele chega ao portal. Se tiver bug, ele explode, e você conserta e tenta de novo.

▶ Começar agora

Por que aprender a programar jogando funciona

A maior barreira de quem começa a programar não é a dificuldade, é a falta de motivação. Ler sobre for e if sem um objetivo é cansativo. No HackBot, cada conceito novo resolve um problema concreto: um corredor longo demais pede um for, um bug escondido pede um if, uma porta trancada pede o DOM.

Esse ciclo de tentar, errar e corrigir é exatamente o que programadores profissionais fazem todos os dias. O jogo transforma o erro em parte da diversão: os erros viram personagens, como o Undefined e o InfiniteLoop, e a mensagem explica o que deu errado em português simples.

Como funciona o HackBot

1. Assista à aula

Antes de cada conceito, a Profa. Byte explica com analogias: variável é uma caixa com etiqueta, for é a placa que conta as voltas de uma corrida.

2. Escreva o código

Um editor de verdade, com cores, autocompletar de chaves e botões com os comandos que você já desbloqueou.

3. Aperte RODAR

O robô executa seu programa com animação. Você vê, passo a passo, o que cada linha faz.

4. Ganhe estrelas

Chegue ao portal, colete todos os chips e resolva com poucas linhas. Código enxuto vale 3 estrelas.

Veja o código da primeira fase. É JavaScript puro, o mesmo usado em qualquer site:

// Cada linha é uma ordem para o robô
robo.mover();
robo.mover();
robo.mover();

Algumas fases depois, o mesmo problema fica elegante com um laço de repetição:

for (let i = 0; i < 9; i++) {
  robo.mover();
}

O que você aprende: do zero ao DOM

O curso “JavaScript: do zero ao DOM” tem 25 fases organizadas em 8 módulos. Cada módulo libera ferramentas novas para o seu robô:

  1. Primeiros comandos: sequência de instruções e argumentos, como robo.virar("direita").
  2. Repetição: o laço for e como evitar código repetido.
  3. Memória: variáveis com let e const, números, operações e strings (textos), incluindo template strings.
  4. Decisões: if, else, comparação com ===, o laço while e os operadores lógicos &&, || e !.
  5. Funções: criar seus próprios comandos com function, usar parâmetros e devolver valores com return.
  6. Listas e objetos: arrays, for...of, .length, índices e objetos com propriedades.
  7. Hacker de CSS e HTML: seletores, opacity, transform, tags e atributos.
  8. Mestre do DOM: querySelector, querySelectorAll, classList, textContent, createElement, appendChild e eventos com addEventListener.

Ao terminar, você domina os fundamentos que aparecem em qualquer curso de desenvolvimento web e entende como um site muda quando você clica em algo: é o JavaScript mexendo no DOM.

Exemplo: manipulando o DOM dentro do jogo

Na fase “Botão Mágico”, uma porta magnética só abre quando o robô pisa num botão. Para passar, você programa um evento, igual aos sites de verdade:

const botao = document.querySelector("#botao");
botao.addEventListener("pisar", () => {
  document.querySelector("#porta").classList.add("aberta");
});

Arena online: sua IA contra a de outros jogadores

Depois do módulo de decisões, abre a Arena. Lá você escreve uma função turno(eu, radar), que é a inteligência artificial do seu robô, e enfrenta cinco rivais cada vez mais espertos. Ao vencer um rival, você pode ler o código dele e aprender com o inimigo.

Com uma conta grátis, sua IA entra no ranking online com pontuação Elo e duela com robôs de outros alunos. O código dos adversários fica secreto: você só vê a batalha.

Perguntas frequentes

Dá para aprender JavaScript jogando?

Sim. No HackBot você escreve JavaScript de verdade (não blocos) para controlar um robô. Cada fase exige usar o conceito novo, como for, if, funções ou o DOM, e o jogo mostra na hora o resultado do seu código.

O HackBot é gratuito?

Sim, é 100% gratuito e roda no navegador, sem instalar nada. Criar conta também é grátis e serve para salvar o progresso e entrar no ranking.

Preciso saber programar para começar?

Não. A primeira fase começa com uma única linha: robo.mover();. Antes de cada conceito novo há uma aula animada e narrada com analogias do dia a dia.

Para qual idade o HackBot é indicado?

Para quem já lê com fluência, a partir de uns 10 anos, até adultos iniciantes. Professores também usam em sala de aula, pois cada aluno tem sua conta e progresso.

O que eu aprendo no HackBot?

Comandos e sequência, argumentos, laços for e while, variáveis, strings, if/else, operadores lógicos, funções, parâmetros, return, arrays, objetos, CSS, HTML e manipulação do DOM com querySelector, textContent, createElement e addEventListener.

Qual a diferença entre o HackBot e outros jogos de programação?

O código é JavaScript real, o mesmo usado em sites. Além das fases, há uma arena online em que sua inteligência artificial (uma função turno) batalha contra robôs de outros jogadores e sobe num ranking com pontuação Elo.
